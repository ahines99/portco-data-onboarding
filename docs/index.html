The audit that changed the checks

A ten-agent audit recorded 23 findings. One source used Revenue as an account category: a 100.00 credit became zero recognized revenue while every reconciliation check passed. Both calculators shared the same unchecked semantic assumption.

The repair makes canonical categories executable contracts. Unknown classifications block affected metrics; normalization requires a reviewed transform. Regression coverage also addresses rejected joins, revoked approvals and stale-worker publication.

Evaluation and boundaries

The SaaS demo publishes nine reconciled metrics. Typed CSV and read-only PostgreSQL extraction have synthetic end-to-end verification. A real historical retail exercise imported and profiled 10,000 rows; it did not certify financial metrics.

The original unfamiliar-schema probe produced zero proposals and matched 0/10 targets. Later frozen agent-authored corpora exposed additional safety failures. Repairs increased review coverage, with wrong proposals and substantial review effort still present. The failed results are preserved; remediation is feedback-informed, not untouched held-out validation.

Publication is local. There is no accepted live backend, warehouse deployment, independent human usability result or measured business savings. The public presentation runs on free GitHub Pages. Optional hosted deployment and the bounded local semantic executor have separate acceptance limits.
