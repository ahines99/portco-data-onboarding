# Private intake and task freeze

Copy this checklist into approved private storage; do not fill names, secrets or source values
into this tracked file. Link private documents with opaque references in the measurement record.

Before starting, record and confirm:

- Participant roles, operator's relationship to the developers, separate reviewer competence and
  any reviewer relationship to Alex. Record voluntary participation and withdrawal procedure.
- Data owner's authorization reference: purpose, fields, people, approved local storage and backups,
  retention deadline, deletion method and whether any external model/metadata disclosure is allowed.
- Source minimization and residual disclosure review, including category labels and small groups.
  Keep any pseudonymization key separately with the data owner. Do not equate pseudonyms with anonymity.
- Separate permission status for public aggregate results, quotes and company identification.
- Task card, exact deliverables, selected entities/metrics, reference date, known unsupported scope,
  required units/joins, row-retention rules, expected exclusions and independent reference answers.
- Input and manifest hashes, source version, application commit, lock hash, tool revision, environment,
  and actual client/model if separately approved. Stop if the application worktree is not frozen.
- Manual/assisted arms, matched tasks, order, time cap, training allowance, stopping rules and how
  failures, withdrawals and missing observations will be represented.
- Allowed assistance, how it is requested and recorded, and the channel for reporting a stop.

Use [task cards](task-cards.md) to select scope. Both arms receive comparable input and must satisfy
the same output contract, including checking/review. Prefer counterbalanced order on disjoint,
comparable inputs; one repeated input creates a learning effect that must be disclosed.

Freeze the sheet and expected answers before the first arm. Reference answers must not be written
after inspecting the assisted proposals. Record approved plan amendments, but do not silently
change the task or correctness criteria to turn a failure into completion.

Stop for unauthorized disclosure/access, unexplained financial discrepancies, withdrawal or the
agreed time cap. Preserve the private attempt record. Local role separation does not protect
against a privileged operator editing the database; that actor is outside the security boundary.
